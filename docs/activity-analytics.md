# Activity and Analytics

Workspace activity records safe metadata for recent items, notifications, favorites, and the `/analytics` dashboard. Analytics shows browser-local counts, categories, activity over time, storage estimates, and quality trend with accessible tables.

Analytics is disabled by default and begins only after explicit local consent. Opt-out disables collection and clears existing analytics. Events are bounded, date-filterable, exportable, clearable, and disableable. Prompt/document bodies, free-text searches, imported files, feedback text, Assistant messages, exact identity, credentials, and secrets are not analytics fields. The storage manager reports estimates and warnings but never silently deletes user-authored data.
