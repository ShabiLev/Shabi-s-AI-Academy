# Learning intelligence

Guidance modes change explanation depth, not safety:

- Teach: concepts, reasons, checkpoints and next learning step.
- Guided: concise instructions with confirmations.
- Expert: compact operational detail.
- Audit only: evidence and findings; no implementation action.

The Skill Map begins with 12 domains: prompt engineering, agent design,
orchestration, product definition, architecture, frontend, data/storage, QA,
accessibility, security, release engineering and research. Levels are
`not-started`, `exploring`, `practicing`, `demonstrated`.

Evidence may come only from completed lessons, exercises and missions. Page
views, route events and time spent never raise a skill level. Recommendations
identify the weakest relevant skill and link to an existing lesson or a safe
practice mission.

A `ContextPack` stores a localized name, bounded note, local entity references,
source labels and timestamps. It never embeds credentials or silently copies
complete private documents into analytics/evidence.
