# Roadmap

The Roadmap uses typed `completed`, `inProgress`, and `planned` states. Version 1.7 delivers the public no-login beta, bounded scheduled Radar publication, reviewed fallback, versioned local guest profile, inspectable local personalization, daily briefing, and consent-off-by-default analytics. Production authentication, cloud guest profiles, cross-device sync, email digest, unrestricted push, public administration, and arbitrary source submission remain planned or explicitly out of scope without date promises.
